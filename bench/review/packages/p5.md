# Plan — order-create-audit
Path: standard · Type: feature · Tasks: 3

## Goal
Every order records when it was created, and the list can be narrowed to orders created since a given date.

## Non-goals
Configuration: no new environment variables, no CORS, nothing this service reads from its environment that it does not read today. A migration for existing data — the seeds carry their dates.

## Design
### Modules
`src/store/orders.js` — the field and the seeded values. `src/services/orders.js` — the stamp and the `since` filter. `src/routes.js` — the query parameter.
### Dependency direction
`routes → services → store`, one way. The service returns data and throws; writing a response stays `src/http/respond.js`'s job, and only its.
### Interfaces
`Order` gains `createdAt: string` · `list(status: string | null, since?: string): Order[]`
### Invariants & failure modes
`createdAt` is one format everywhere it is written or compared, so the comparison the filter makes means the same thing for a seeded order and a created one.
### Data & scale
Three seeded orders, a handful created per session. String comparison is enough at this size.
### Precedent
`src/store/orders.js:7` for the seeds; `src/services/orders.js:12` for where a filter belongs.
### Refactor in scope
The `Order` typedef and its three seeds. The route table's own tests may gain the case for the status the POST row already carries.
### External APIs
None.
### Architecture alternatives
Storing an epoch number was declined for readability of the seeds; the format has to be stated in the invariant either way.

## Tasks
### T1. The field
Files: `src/store/orders.js`. Acceptance: every seeded order carries a `createdAt`, and the typedef says so.
### T2. The stamp and the filter
Files: `src/services/orders.js`, `src/routes.js`. Acceptance: a created order carries the date it was created, and `since` returns exactly the orders at or after it — seeded and created alike.
### T3. Cover the route table
Files: `test/routes.test.js`. Acceptance: the POST row's status is the one the table declares.
