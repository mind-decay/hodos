# Platform notes — Claude Code facts hodos depends on

Dated, verified facts about Claude Code behavior, and open checks with their fallbacks. When a component depends on platform behavior, the fact must be here with the command that verified it. Docs move; this file is the digest the code is built from. Sources: `research/02` (official docs, 2026-08-30), CHANGELOG up to v2.1.251; corrections of 2026-09-02 from `code.claude.com/docs/en/setup` and `/sub-agents`, prompted by `research/05 §5`.

## Conventions for this file

One row per fact; the date of verification; the command or doc URL. A fact contradicted by observation is corrected here first, then the code — never the other way round.

**The `Source` column and what it obliges.** `docs` means the official documentation states it and the row carries the page; `observed` means a run on this machine produced it and the row carries the command and the date; `docs + observed` means both. An `observed` fact is a dependency on behavior nobody promised to keep — Hyrum's law — and the bench arm rests on three of them (31, 32, 35). So: **on a Claude Code upgrade that crosses a minor version, re-probe every `observed` fact the bench or a hook depends on, and re-date the row.** A row that fails the re-probe is corrected here before any code moves.

A `docs` fact is not permanent either: facts 12, 13 and 18 were true on 2026-08-30 and wrong on 2026-09-02. When a stage's premise is a `docs` row, the stage re-reads the page rather than the row.
